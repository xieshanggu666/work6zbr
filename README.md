# 🏅 青春杯 · 体育赛事编排与成绩管理系统（SportFlow）

一个综合性运动会/联赛的赛事编排与成绩管理平台，支持多项目、多赛制（单循环 / 小组赛+淘汰赛 / 单败淘汰 / 田径计时）编排，参赛队伍与运动员注册、赛程自动排定、比分录入、积分排名、奖牌统计与成绩册输出。适用于校运会、省市级联赛等场景。

> 视觉风格：**明亮运动活力风**（浅色底 + 活力橙/绿茵/天际蓝），与工程内其他项目（深色科技风）刻意区分。

## 技术栈

- **前端**：Vue 3 + Vite + Pinia（状态管理）+ 原生 SVG/条形可视化
- **后端**：Express + Node.js 内置 `node:sqlite`
- **数据库**：SQLite（`server/event.db`）
- **通信**：REST API，Vite 代理 `/api` 到后端
- **启动**：`concurrently` 并行拉起前后端（后端 4170 / 前端 5203）

## 数据模型（SQLite 表）

| 表 | 说明 |
|----|------|
| `sports` | 比赛项目（类别 / 赛制 format：roundrobin·group_knockout·knockout·track；含队伍/运动员名额） |
| `units` | 参赛单位（学院/俱乐部，含主题色） |
| `teams` | 队伍（归属单位 + 项目 + 资格状态 status：pending·approved·rejected·withdrawn·revoked） |
| `athletes` | 运动员（田径等单项，含资格状态） |
| `venues` | 场地 |
| `referees` | 裁判 |
| `matches` | 对阵场次（小组/半决赛/决赛/季军，比分、决胜比分、胜方与状态；scheduled·finished·cancelled，note 记录取消原因） |
| `entries` | 单项成绩（mark + rank） |
| `standings` | 积分榜（赛/胜/平/负/进失/积分/排名，仅含 approved 队伍） |
| `medals` | 奖牌榜（金/银/铜） |

## 参赛资格审核流程

**「🛂 资格审核」页**贯穿报名 → 审核 → 名单 → 赛程的完整闭环：

1. **单位报名**：各单位提交队伍（球类）或运动员（田径等单项），初始状态为「待审核」；名额（组委会可按项目设置队伍/运动员上限）已满时报名被拦截。
2. **组委会审核**：审核资格与名额
   - ✅ **通过**：状态转 approved，纳入参赛名单与积分榜；球类队伍自动补排对阵（循环赛补与在册队伍的全部对阵，小组赛编入人数较少的组；纯淘汰项目种子对位固定，不自动插入）。
   - ⛔ **驳回**：记录驳回原因，释放名额，可在「退报/驳回/撤销」标签中追溯。
3. **退报 / 资格撤销**（approved → withdrawn / revoked）自动**联动处理受影响的对阵及成绩**：
   - 未赛场次直接删除；已完赛场次作废（比分/胜方清空、置 `cancelled`），积分榜与奖牌随即重算；
   - 淘汰赛半决赛作废后，**另一方轮空晋级**，依赖该场的决赛/季军对阵同步失效，之后可重新编排下一轮；
   - 田径运动员退出则删除成绩行并按剩余在审运动员重新排名、重算奖牌；
   - 非 approved 队伍不出现在积分榜、对阵编排与奖牌结算中，作废场次不允许再录成绩。

## 核心算法

- **单循环**：两两配对生成 `n*(n-1)/2` 场，积分最高者为冠军。
- **小组赛 + 淘汰赛**：分组循环 → 按每组积分排名（胜 3 / 平 1 / 负 0，净胜球次序）→ `A1 vs B2`、`B1 vs A2` 交叉半决赛 → 决赛 + 季军战。
- **单败淘汰**：半决赛 → 胜者晋级决赛、负者争季军。
- **淘汰赛平分决胜**：半决赛/决赛/季军战常规时间战平时，必须录入加时/点球决胜比分（不得再次持平），系统以决胜结果确定胜方并持久化到 `matches.winner`；晋级编排、奖牌结算、对阵展示统一读取该字段，未决胜前不会生成下一轮对阵。决胜比分不计入进失球。
- **田径计时**：成绩升序自动排名，前 3 结算金/银/铜。
- **奖牌统计**：按单位累计各项目冠军/亚军/季军。

淘汰赛对阵不是一次性预排，而是**按当前小组赛/半决赛真实赛果动态生成**——在"赛程编排"页当小组赛（或半决赛）完赛后点击"🧩 编排下一轮淘汰赛"，系统读取实时排名后自动填入对阵。

## 核心流程

单位报名（队伍/运动员）→ 组委会审核资格与名额 → 通过后纳入参赛名单、自动补排赛程 → 录入比分（成绩录入页）→ 积分榜/排名自动更新 → 完赛阶段动态编排下一轮淘汰赛 → 单项目决出冠亚季 → 汇总至奖牌榜与报表中心；退报或资格撤销时，受影响的对阵、成绩、积分与奖牌自动联动处理。
